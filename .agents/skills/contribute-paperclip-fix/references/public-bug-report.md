# Public bug report

Include:

- concise observed and expected behavior;
- deterministic reproduction;
- Paperclip commit/version and deployment mode;
- sanitized logs or error payload;
- root-cause evidence when confirmed;
- acceptance criteria;
- related public issues and PRs.

Exclude private company IDs, internal issue identifiers, private URLs, tokens,
customer data, and infrastructure details unnecessary to reproduce the defect.
